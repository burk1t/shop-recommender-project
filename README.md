# Интернет-магазин «Дом, кухня и умный комфорт»

Проект системы с рекомендательной системой.

## Состав проекта
- `data/` — каталог товаров, покупатели, события, 5 матриц (CSV)
- `diagrams/` — ERD, архитектура, sequence-диаграммы
- `report/` — отчёт Word
- `calculations/` — ручные расчёты в Excel
- `figma/` — ссылка на прототип

## Масштаб
8 категорий / 24 подкатегории / 200 товаров / 10 покупателей / 4 группы / 12 предпочтений.
